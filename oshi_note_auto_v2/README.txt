OSHI NOTE v2 - 推し別設定・活動別貯金

使い方
1. index.html をブラウザで開くと基本機能を試せます。
2. 推し管理で推しの名前、SNS URL、活動ごとの加算額を登録します。
3. 「活動を記録」で推し・活動種別を選ぶと設定金額が入力されます。活動URLが重複していると二重加算を防ぎます。
4. 「設定・バックアップ」からJSON/CSVを保存できます。
5. HTTPSで公開する場合は、GitHubリポジトリのルートに index.html、manifest.json、sw.js、icon.svg を置き、GitHub Pagesを設定します。

重要：このv2は推し別設定、活動の手動記録、URLベースの重複防止、履歴、バックアップを実装したプロトタイプです。X/Instagram/YouTubeの自動検知・自動加算はまだ接続されていません。自動検知には各サービスの公式API、定期実行するバックエンド、秘密情報の保管、利用規約・API利用枠の確認が別途必要です。GitHub Pages単体ではSNSをバックグラウンド監視できません。

データはこのブラウザの localStorage に保存されます。端末やブラウザ間で自動同期されません。定期的にバックアップしてください。
